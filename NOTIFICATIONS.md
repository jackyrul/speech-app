# 🔔 Пуш-уведомления — настройка

Напоминания работают так: раз в день **GitHub Actions** (бесплатно) запускает
скрипт, который шлёт пуш, если ты сегодня ещё не тренировался. Подписка
устройства хранится в твоём приватном Gist (там же, где прогресс).

## Что нужно сделать один раз

### 1. Добавить два секрета в репозиторий
`Settings → Secrets and variables → Actions → New repository secret`

| Имя | Значение |
|-----|----------|
| `VAPID_PRIVATE` | `6TTaoqb4qwU1jZjcFyC_CPcKfQpdbNpdzZDVHIJsjOw` |
| `PUSH_GH_TOKEN` | твой токен `ghp_…` с правом **gist** (тот же, что для синхронизации) |

> Публичный VAPID-ключ уже вшит в приложение и в workflow — его прятать не нужно.

### 2. На телефоне
1. Открой приложение как **PWA** (иконка с экрана «Домой», не в Safari).
2. Вкладка **Прогресс → 🔔 Напоминания → «Включить напоминания»**.
3. Разреши уведомления. Подписка сохранится в Gist.

### 3. Проверка
`Actions → Daily reminder → Run workflow` — придёт тестовое уведомление
(если сегодня ещё не было тренировки).

## Время напоминания
По умолчанию **17:00 UTC** (≈20:00 Киев). Поменять — в
`.github/workflows/notify.yml`, строка `cron: '0 17 * * *'`.

## Важно про iOS
- Пуш работает **только** в установленном PWA (iOS 16.4+), не в браузере.
- Если удалить и переустановить иконку — включи напоминания заново
  (создастся новая подписка).
